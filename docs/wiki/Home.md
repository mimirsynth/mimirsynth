# MimirSynth

**MimirSynth** is a memory for AI agents. It stores what your agents (and you) learn as a **knowledge graph with history**: facts are not overwritten, they are *invalidated* and it keeps when they were true. On top of that graph it adds users and permissions, a quarantine to review what agents write, a search that mixes facts, original texts and documents, and a web interface to explore and maintain it.

This wiki is the complete user guide, in English and [in Spanish](Inicio). If you are looking for the code or want to contribute, it is in the [repository](https://github.com/MimirSynth/mimirsynth).
