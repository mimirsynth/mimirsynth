# MimirSynth

**MimirSynth** es una memoria para agentes de IA. Guarda lo que tus agentes (y tú) aprendéis como un **grafo de conocimiento con historia**: los hechos no se sobrescriben, se *invalidan* y se conserva cuándo fueron ciertos. Sobre ese grafo añade usuarios y permisos, una cuarentena para revisar lo que escriben los agentes, una búsqueda que mezcla hechos, textos originales y documentos, y una interfaz web para explorarlo y mantenerlo.

Esta wiki es la guía de usuario completa, en castellano y [en inglés](Home). Si buscas el código o quieres contribuir, está en el [repositorio](https://github.com/MimirSynth/mimirsynth).
