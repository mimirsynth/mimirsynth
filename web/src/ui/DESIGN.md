# Design rules

The design rules of the interface now live in [`DESIGN.md`](../../../DESIGN.md) at the root of the repository: tokens, shape, heights, buttons, colour and contrast, page structure, and what is not done. The tokens themselves are in [`web/src/theme.css`](../../theme.css); how to use each kit component is in [README.md](README.md).

If a rule changes, change it there and in `theme.css`, never screen by screen.
